# Ozelot Vanillaの作品実績

## 概要

### 自己紹介

* Web，ゲーム，音楽を横断する対話的な仕組みを制作しています。
* 実装，設計意図の翻訳，音・対話表現の発想をつなぐ立場で制作しています。
* 抽象的な発想を，実際に遊べる形・試せる形へ落とし込むことを得意としています。
* 実装だけでなく，設計側・表現側との相談や意図共有にも慣れています。

### 強み

* TypeScriptを用いたWeb前端開発と開発支援道具の制作
* Godot Engineを用いたゲーム・対話的作品の実装
* 新しい技術や制作環境を学び，適応する力

### 得意な役割・向いている領域

* 抽象的な設計意図をもとに，ゲームの仕組みを実装するゲームエンジニア
* 特定の制作環境や要求に合わせた対話的な仕組み・開発支援道具の制作
* 利用者の反応を考慮したUI・遊びの実装
* デザイナー，プランナー，研究者との橋渡しを行う創造的な技術職

## 主な制作物

### DeepMaze

* 概要: Godot Engineで開発している迷宮探索ゲームです。
* 役割: プログラマー，ゲーム設計の提案
* 実装した内容: ゲーム進行，能力・スキルシステム，UI実装，ゲーム基盤システム
* 解決した課題: Figma上のUIとGodot上の実装との差異，ゲームシステムの保守性，ゲーム進行の拡張性
* GitHub Public Repo: [https://github.com/OzelotVanilla/deepmaze__public](https://github.com/OzelotVanilla/deepmaze__public)

### CattyPiano

* 概要: ブラウザ上で動作するピアノ・リズムゲームです。
* 役割: プログラマー，デザイナー，作曲
* 解決した課題: 入力遅延や不自然な反応など，操作感に関わる問題の改善
* GitHub Repo: [https://github.com/OzelotVanilla/CattyPiano](https://github.com/OzelotVanilla/CattyPiano)

### jjdev

* 概要: 端末上でjj-vcsを使う際，`jj log`を同時に確認しやすくするCLI道具です。
* 役割: プログラマー
* 実装した内容: 右側にjjの履歴木を表示する領域を開き，jjの作業状態の変化を監視し，状態が変わった時に表示を更新する仕組み
* 解決した課題: 多くのjjコマンドでcommitを指定する際に使うchange IDを確認するため，頻繁に`jj log`を実行する手間
* GitHub Repo: [https://github.com/OzelotVanilla/jjdev](https://github.com/OzelotVanilla/jjdev)

## その他の技術制作

### Punch the Red

* 概要: 8051系MCUと16x16 LED行列を用いて実装した簡単なリズムゲーム試作です。
* 示していること: ハードウェアへの関心，低水準寄りの実験への興味
* GitHub Repo: [https://github.com/OzelotVanilla/PunchTheRed](https://github.com/OzelotVanilla/PunchTheRed)

### TypeScript to SuperCollider Transpiler

* 概要: TypeScriptからSuperColliderのSCLangへ変換するtranspilerです。
* 示していること: 言語処理，開発支援道具への関心
* GitHub Repo: [https://github.com/OzelotVanilla/TypeScript_to_SuperCollider](https://github.com/OzelotVanilla/TypeScript_to_SuperCollider)

### ThemeCesno

* 概要: 「Quiet Cesno」をもとにした，より彩度の高いVSCode主題です。
* 示していること: 開発環境への関心，美的感覚を含めた道具作りへの意識
* GitHub Repo: [https://github.com/OzelotVanilla/ThemeCesno](https://github.com/OzelotVanilla/ThemeCesno)
